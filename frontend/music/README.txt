THƯ VIỆN NHẠC NỀN
- Thả các file .mp3 (hoặc .ogg/.m4a/.wav) vào thư mục này.
- App tự liệt kê qua /api/music -> hiện trong ô "Thư viện nhạc nền" của thanh công cụ.
- Tên hiển thị lấy từ tên file (gạch dưới/gạch ngang -> dấu cách). Vd: mua_dem.mp3 -> "Mua Dem".
- Nguồn nhạc miễn phí bản quyền: Pixabay Music, FreePD, Incompetech, YouTube Audio Library.
- KIỂM TRA GIẤY PHÉP nếu sau này thương mại hoá (CC0/Pixabay = thoải mái; CC BY = phải ghi công).
