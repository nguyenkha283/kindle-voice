Thả 4 clip mẫu GIỌNG CỦA BẠN vào đây (WAV mono, 6-8 giây, sạch), đúng tên:

    trung_tinh.wav   - Kể chuyện (đọc phẳng, bình thản)   [BẮT BUỘC nếu muốn bật register]
    doi_thoai.wav    - Đối thoại (sinh động hơn)
    tinh_cam.wav     - Tình cảm (ấm, chậm)
    goi_cam.wav      - Gợi cảm (trầm, nhẹ, thân mật)

- Thiếu file nào thì sắc thái đó tự fallback (vd goi_cam -> tinh_cam -> trung_tinh).
- Chưa có file nào -> app đọc bằng giọng mặc định như cũ.
- Xem hướng dẫn thu ở file "huong-dan-thu-clip-mau.md".
- Sau khi thả file, khởi động lại app (run_vieneu). Kiểm tra: mở /api/registers.
